# Agent Lens

### Open-source observability for AI coding agents.

See exactly what your AI coding agent is doing.

**Agent Lens** records agent sessions and turns them into a beautiful, searchable timeline of:

- 🧠 Model calls
- 🔧 Tool calls
- 💻 Shell commands
- 📁 File changes
- ❌ Errors & retries
- 💰 Token & cost estimates
- ⏱️ Session duration
